---
name: asd
description: Rephrase text using ASD-STE100 principles. Use when asked for STE wording.
---

Rephrase only the requested text. Preserve its meaning, scope, requirements,
conditions, exceptions, and uncertainty. Do not add requirements or procedures.

- Use short, complete sentences. Keep one instruction per sentence unless actions occur at the same time.
- Give each paragraph one topic. Use lists for steps or complex conditions.
- Use the active voice. Make the actor and action clear.
- Use simple, direct words. Use one term for each concept.
- Use verbs for actions instead of noun phrases.
- Keep necessary technical terms. Do not replace precise terms with vague words.
- Use the imperative for instructions. Put conditions before the actions they govern.
- Remove repetition and unnecessary words, but keep facts and qualifications.
- Preserve code, commands, identifiers, links, numbers, and units.

Ask if an ambiguity prevents a faithful rewrite. Otherwise, return only the
revised text unless the user requests an explanation.

Apply STE principles. Do not claim full compliance without checking the complete
rules and dictionary.

Reference: [Official standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf).
